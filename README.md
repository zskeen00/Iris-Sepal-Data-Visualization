# Iris-Sepal-Data-Visualization
# The goal of this project was to analyze and visualize key relationships in the Iris dataset using Python. I generated a box plot to compare sepal length distributions across species, explaining the significance of each element (quartiles, median, whiskers, and outliers). I also created a scatter plot to explore the relationship between sepal width and sepal length, using color to distinguish species and adding a clear legend. These visualizations helped highlight species-specific patterns in the data and demonstrated foundational skills in data analysis and interpretation.
